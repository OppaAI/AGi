# AGi avatar asset

`Grace.vrm` is a copy of the `Original.vrm` VRoid sample distributed in the
Aiko-chan repository. Its embedded VRM metadata links to the VRoid Hub sample
license, which permits modification and redistribution, including commercial
use, and does not require attribution:

https://hub.vroid.com/license?allowed_to_use_user=everyone&characterization_allowed_user=everyone&corporate_commercial_use=allow&credit=unnecessary&modification=allow&personal_commercial_use=profit&redistribution=allow&sexual_expression=allow&version=1&violent_expression=allow

The model is used as a temporary avatar until the custom Grace model is ready.
