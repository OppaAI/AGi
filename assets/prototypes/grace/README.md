# Grace character blockout

Editable Blender scene and a GLB export of the current stylized character blockout.
This is a rough primitive-based prototype with a basic rigid-parent armature. It is
not production-ready, not weight-painted for smooth deformation, and not a VRM.

- `Grace_Blockout.blend` — editable Blender source scene
- `Grace_Blockout.glb` — interchange preview/model
- `Grace3D_download.zip` — both files
