# Grace anime-style Blender prototype

Grace_Anime.blend is an editable Blender 4.3 scene built from the VRoid
AvatarSample_A base in Aiko-chan/assets/Original.vrm, with new Grace outfit
and hair meshes. Embedded textures are packed. The source humanoid rig and
facial shape keys are retained; new clothes use armature vertex groups.
The scene is posed for a preview; clear arm pose transforms for its rest T-pose.

This is an approximate first clothing/hair pass, not a faithful reconstruction
of the turnaround or a finished VRM. Garment fit, hair silhouette, deformation,
facial expressions, and VRM export need further artist review. No spring-bone
simulation or VRM-specific setup has been added to the generated clothing/hair.
