# Grace’s Canvas Studio

Open **Canvas** from the console. The artboard stays at 1000 × 650 pixels;
the surrounding workspace adapts to desktop and mobile screens. Theme follows
the console’s saved light/dark preference.

## Making artwork

Ask Grace for a subject, a palette and lighting, for example:

> Paint a quiet mountain lake at sunset, with lavender mountains, apricot light,
> reflections, and leafy silhouettes in the foreground.

Then ask for targeted refinements such as “add warm highlights to the leaves”.
Grace can use filled cubic curves, smooth contours, directional and radial
gradients with up to eight colours, transparent shading, brush strokes, and text.
Her instructions favour composition, depth and consistent lighting. Drawing
quality depends on the selected LLM; no image generation service is required.
Grace receives structured artwork data rather than a screenshot, so she cannot
visually inspect the rendered result.

The right inspector contains tools, four palette families, separate stroke/fill
colours, painting controls, typography and a layer list. Select a layer to move
it, apply styling, reorder or delete it. Each retained drawing object is a layer;
layer groups, raster masks and photo editing are outside this studio’s scope.
The optional **Open colour study** loads a prepared, editable landscape example;
it is not a drawing generated by the model. Undo restores the previous canvas.

Keyboard shortcuts outside text fields: **B** brush, **E** eraser, **V** select,
**L** line, **R** rectangle, **O** ellipse, **T** text, **Ctrl/Cmd+Z** undo,
**Ctrl/Cmd+Shift+Z** redo. Delete/Backspace removes the selected object when
the canvas has focus.

## Saving and resources

- Artwork autosaves in this browser. It is not synchronized across devices.
- **Save artwork** downloads editable JSON; **Open artwork** restores it.
- **Export PNG** creates a white-backed image without selection outlines.
- At most 100 objects are retained. Undo keeps up to 50 snapshots.
- Grace’s context uses bounded artwork summaries and recent dialogue instead
  of carrying full coordinate histories into every request. Her output budget
  is 3072 tokens; complex artwork should be developed over several requests.
  Actual context fit depends on the model, tokenizer and persona prompt.
- During animated playback, completed layers are cached once per action so
  the browser only repaints the current mark each frame. Reduced-motion
  preferences disable the replay animation.

The tools work when ROS is disconnected. Asking Grace requires AIVA, its
configured LLM, and the console’s ROS bridge. Offline browser tests cover tool
operation and file handling; simulated ROS events cover drawing playback.
